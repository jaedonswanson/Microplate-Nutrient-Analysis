# Recipes
## Stock ammonium solution (100ppm)
#### Water Samples
1. 0.0094g Ammonium Sulfate + 20mL deionized water
#### Soil Samples
1. 0.0094g Ammonium Sulfate + 20mL soil matrix solution
#### Resin Samples
1. 0.0094g Ammonium Sulfate + 20mL resin extract solution
## Sodium Salicylate Solution
*Store in refrigerator when done*
1. Weigh out 6.8g Sodium Salicylate and add to 100mL volumetric flask
2. Weigh out 5.0g Sodium Citrate and add to flask
3. Weigh out 5.0g sodium tartrate and add to flask
4. Weigh out 0.025g nitroprusside and add to flask
5. Bring to volume with deionized water
## 1.5M NaOH
*Store in refrigerator when done*
1. Weigh out 15.0g sodium hydroxide
2. add to 250mL volumetric flask and bring to volume with deionized water
## Bleach Solution
*This solution is unstable and should be made fresh each analysis*
*When doing analysis on KCl extracts, the bleach concentration needs to be higher. Use 0.565mL of concentrated bleach*
1. Add 0.375mL concentrated bleach to a 25mL volumetric flask
2. Bring to volume with 1.5M NaOH
# Procedure
Samples should be run differently depending on expected nutrient concentration.

1. Mix 1mL of 100ppm stock solution with 9 mL matrix solution (Deionized water or soil matrix)
	- **This is the 10ppm stock solution**

## Loading the microplate
- **If running pultiple plates of KCl extracts, add the sodium salicylate reagents *imedietly* after the bleach for each plate. Do not add all sodium salicylate to the plates, and then add bleach for the plates**
- *Do **NOT** add any reagents before loading the microplate*
- *Change pipette tips each time when loading samples and standards*
1. Load 3 replications of the standard in the first 3 columns
	1. If using the **low** standard 80 $\mu$L of the standard
	2. If using the **high** standard 20 $\mu$L of the standard
2. Load 3 replications of each sample in the rest of the wells of the microplate
	1. If using the **low** standard 80 $\mu$L of the sample
	2. If using the **high** standard 20 $\mu$L of the sample
3. After loading, use a multichannel pipette to add the salicylate solution and bleach solution
	1. If using the **low** standard 60 $\mu$L of each of the solutions
	2. If using the **high** standard 90 $\mu$L of each of the solutions
4. Label the plate with labeling tape
5. Note the current time and time to read the plate
6. incubate at room temperature for 3 hours
*The samples should turn a blue color. If any change rapidly and go beyond the darkest standard, make note and disregard the samples. It will be necasary to dilute these samples to analyze*
## Running the Experiment
1. Open the software for the microplate reader
2. If prompted, select 'simple' mode
3. Select 'open existing protocol'
4. Go to desktop $\to$ MicroplateNitrate_BH $\to$ Ammonium
5. Select 'Read New' and follow the prompts. Ensure the lid is off before starting the read
6. Do not export to excel, just copy the readeings and paste them into an excel workbook
	1. Ensure everything is labeled correctly
	2. Save workbook to MicroplateNitrate_BH with a good name
7. Check the standard curve and the R$^2$ value, anything above $0.98$ is fine.
# Misc. Notes
- Example of diluting a sample
	- 5x dilution
		- separate vial: 100$\mu$L sample + 400$\mu$L matrix solution
			- add 10$\mu$L or 100$\mu$L to well depending on which standard is being used (low = 100$\mu$L, high = 10$\mu$L)
		- Separate well: 2$\mu$L sample + 8$\mu$L matrix solution for high standard or 20$\mu$L sample + 80$\mu$L matrix solution for low standard
	- Add reagent as normal and note where the diluted samples are located
	- to calculate the concentration: 
		- Real concentration = dilution factor (5 in above example) * concentration of diluted sample
- Samples may have a precipitate settled at the bottom. This should not affect soluble nutrients, but shake to homogenize the concentrations
	- Allow to settle for $\approx$ 5 minutes after shaking
- Make sure to wsh the dishes soon after use. The reagents can dry and form a film that is nearly impossible to remove.
	- Microplates can be washed 5x with RO water and 5x deionized water
- Make sure to examine microplates to ensure they are not scratched and take care not to scratch them
