# Recipies
- ***Preparation of solutions should be conducted in a fume hood when applicable, always use proper PPE***
- ***Tape a kim wipe to the fume hood door to ensure the hood is operating correctly***
- To prevent cross contamination, ensure the scoopula used are cleaned with ethanol and a kim wipe between different powders
- Weigh powders on weighing paper
- Dispose of any waste into a labeled waste container, rinse with deionized water and wash as normal
- Wipe down fume hood with a damp sponge with a bit of alconox detergent when done
## 1.0M HCl
***Wear elbow-high gloves in addition to nitrile gloves when handling concentrated HCl***
1. Measure out $\approx$ 41.65 mL concentrated HCl using a graduated cylinder
2. Pour deionized water about halfway into a 500mL volumetric flask
3. **Slowly** pour the concentrated HCl into the flask
4. Fill the rest of the flask with deionized water
5. Mix by inversion
6. Label Container

## Vanadium Chloride Solution (VCl$_3$) (Nitrate Reagant)
***VCl$_3$ powder releases chlorine gas when exposed to air. This is violently reactive with water. It is crucial this is completed in the fume hood.***
*Keeps for $\approx$ 3 months*
*Store in a dark, cool region (Refrigerator is fine)*
1. Weigh out 200mg of sulfanilamide and add to 250mL beaker
2. Weigh out 10mg (NEDD) and add to the 250mL beaker
3. Add 100mL 1.0M HCl to the 250mL beaker
4. Stir and set aside
5. Place watch glass on top to prevent evaporation
6. Weigh out 400mg VCL$_3$ and add to 250mL beaker
7. Add 50mL 1.0M HCl
8. Stir until dissolved, should change from blue to a more blue-green
9. Gravity filter the VCl$_3$ solution into a 250mL erlenmeyer flask
10. Add the filtered solution to the other solution and stir
## Nitrite Reagent
1. Weigh out 200mg sulfanilamide and add to 250mL beaker
2. Weigh out 10mg NEDD and add to the 250ml beaker
3. Add 100mL 1.0M HCl
4. Store in refrigerator
# Procedure
## Making a Standard Curve
*Samples expected to have low Nitrate/Nitrite content (0-1ppm) should use the **low** procedure and higher concentration should use the **high** procedure
1. Mix 1mL of 100ppm stock nitrate/nitrite solution with 9 mL matrix solution (Deionized water or K$_2$SO$_4$)
	- **This is the 10ppm stock solution**
2. Make the standard curve based on estimated nutrient concentrations

## Loading the microplate
- *Do **NOT** add any reagents before loading the microplate*
- *Change pipette tips each time when loading samples and standards*
1. Load 3 replications of the standard in the first three columns
	1. If using the **low** standard 100 $\mu$L of the standard
	2. If using the **high** standard 10 $\mu$L of the standard
2. Load 3 replications of each sample in the rest of the wells of the microplate
	1. If using the **low** standard 100 $\mu$L of the sample
	2. If using the **high** standard 10 $\mu$L of the sample
3. After loading, use a multichannel pipette to add the nitrate **(VCl$_3$)** ==*or*== **nitrite** reagent
	1. If using the **low** standard 100 $\mu$L of the reagent
	2. If using the **high** standard 190 $\mu$L of the reagent
4. Lightly tap the plate to mix
5. label the plate with labeling tape
6. Note the time and time to read the plate
7. Incubate the microplate at room temperature
	1. Nitrate: 
		1. 5 hours incubation time for water samples
		2. 18 hour incubation time for soil samples
	2. Nitrite
		1. 5-10 minute incubation time
*The samples should turn a pinkish color. If any change rapidly and go beyond the darkest standard, make note and disregard the samples. It will be necasary to dilute these samples to analyze*
## Running the Experiment
1. Open the software for the microplate reader
2. If prompted, select 'simple' mode
3. Select 'open existing protocol'
4. Go to desktop $\to$ MicroplateNitrate_BH $\to$ Nitrate&Nitrite
5. Select 'Read New' and follow the prompts. Ensure the lid is off before starting the read
6. Do not export to excel, just copy the readeings and paste them into an excel workbook
	1. Ensure everything is labeled correctly
	2. Save workbook to MicroplateNitrate_BH with a good name
7. Check the standard curve and the R$^2$ value, anything above $0.98$ is fine.

# Misc. Notes
- Example of diluting a sample
	- 5x dilution
		- separate vial: 100$\mu$L sample + 400$\mu$L matrix solution
			- add 10$\mu$L or 100$\mu$L to well depending on which standard is being used (low = 100$\mu$L, high = 10$\mu$L)
		- Separate well: 2$\mu$L sample + 8$\mu$L matrix solution for high standard or 20$\mu$L sample + 80$\mu$L matrix solution for low standard
	- Add reagent as normal and note where the diluted samples are located
	- to calculate the concentration: 
		- Real concentration = dilution factor (5 in above example) * concentration of diluted sample
- Samples may have a precipitate settled at the bottom. This should not affect soluble nutrients, but shake to homogenize the concentrations
	- Allow to settle for $\approx$ 5 minutes after shaking
- Make sure to wsh the dishes soon after use. The reagents can dry and form a film that is nearly impossible to remove.
	- Microplates can be washed 5x with RO water and 5x deionized water
- Make sure to examine microplates to ensure they are not scratched and take care not to scratch them
